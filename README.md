# ruspack-uptime

Проверка снаружи: живы ли сервисы РусПака на сервере 89.127.203.174.

- **Что проверяется:** портал закупщика, мессенджеры в amoCRM, РОП-бот — их `/health`.
- **Как часто:** раз в 5 минут (расписание GitHub Actions, бывает с опозданием до 5–15 минут).
- **Куда пишет:** Семёну в Telegram от @ruspack_rop_bot. Когда сервис перестал отвечать, раз в 12 часов, пока не ответит, и когда ответил снова.

Зачем: 24.09.2026 хостинг выключил сервер на семь часов, и никто не узнал. «Пульт» портала живёт на том же сервере и о своей смерти сказать не может.

- **Проверить связь:** Actions → uptime → Run workflow → «Только проверить связь с Telegram».
- **Остановить:** Actions → uptime → «…» → Disable workflow.
- **Секреты репозитория:** `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
